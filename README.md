## 先搞清楚：ChinaNet 到底是什么

ChinaNet，学名 AS4134，是中国电信最早也是容量最大的国际出口网络，几乎所有没有做特殊线路优化的国外 VPS，默认走的都是这条路。

这个网络有两个优势：价格便宜，容量大，抗 DDoS 攻击能力强。但缺点也很直接：高峰期严重拥堵，丢包率极高。

用白话说：白天还凑合，一到晚上7点到11点，网页加载、视频卡顿、SSH 延迟飙升，体验断崖式下跌。

---

## 中国电信的线路层级，一次说清楚

中国电信针对国际流量提供了四个层级的解决方案：AS4134 ChinaNet（最便宜、最拥堵）、AS4809 CN2 GT（比 ChinaNet 贵，但自 2019 年起同样出现拥堵）、AS4809 CN2 GIA（最贵、最稳定，去回程全程走 CN2 专线，丢包率极低）、以及最新的 AS23764 CTGNet（性能与 CN2 GIA 等价）。

简单来说：普通线路便宜但晚高峰容易炸，精品线路贵但稳定。

所以，如果你真的需要向中国大陆提供稳定服务，ChinaNet 线路是你应该**主动规避**的，而不是将就的。
